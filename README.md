# OrbitMentor

OrbitMentor is an offline learning planner for aspiring developers. Choose a career path and daily study time, then work through a roadmap, daily quests, short quizzes and portfolio ideas. Mentor suggestions are generated by local rules; the app has no language model or backend service.

## What it includes

- onboarding for six developer paths, current level and daily focus time;
- roadmap tasks, quests, XP, streaks, quiz history and project ideas;
- local progress stored with Zustand and AsyncStorage;
- versioned JSON backup and restore from the Profile screen.

Backup format v1 wraps the current progress in an `orbitmentor` envelope. Import accepts that version and the previous unversioned local payload. The app validates the entire payload before writing it; failed writes leave current progress visible. Backup JSON is readable and unencrypted, so store it privately. Progress stays on this device unless you export a copy.

## Run locally

Use Node.js 22.13+ or 24.3+ and npm:

```bash
npm ci
npm run start
```

To run in a browser:

```bash
npx expo start --web
```

The app works offline with bundled learning content and needs no environment variables. For Android or iOS, install the matching simulator or development build first. This repository session has not verified the app on a native device.

## Checks

```bash
npm run lint
npm run typecheck
npm test -- --runInBand
npx expo export --platform web
```

The browser E2E suite checks onboarding, quest and quiz persistence, corrupt/unavailable storage handling, and backup restore/rejection using the actual web export:

```bash
python -m pip install -r e2e/requirements.txt
python -m playwright install chromium
python -m pytest -q e2e
```

Set `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` if Chromium is already installed at a custom path. A browser test is not a native Android/iOS test.
The suite keeps Chromium's sandbox enabled; on Linux, install the Playwright browser or configure the system Chromium sandbox correctly rather than disabling it.

## Branding and screenshots

App icon, Android adaptive icon, splash image and web favicon are configured in `app.json`. Screenshots in `docs/screenshots/` should come from the running app; label browser captures as web captures and do not present them as native device evidence.

## Tech stack

Expo SDK 58.0.14, React Native 0.88.0, React 19.3.0, TypeScript, Expo Router, Zustand, AsyncStorage, React Hook Form and Zod. See `package.json` and `package-lock.json` for exact installed versions.

## Limitations

There is no account or cloud sync. Clearing app storage removes local progress unless you exported a backup. The backup is plain JSON. Native installability, large-text behavior and screen-reader behavior still need device validation.
